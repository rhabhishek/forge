# Docs: Confluence

- **Acceptance criteria and short specs:** on the work item itself.
- **UX specs and design notes:** a page in the contract's `docs.space_or_path`, under the parent page the project uses for designs. Use the `confluence` skill. Link the page from the work item.
- **Decisions:** a short dated page beside the design notes: context, decision, consequences.
- **Lessons:** recorded by `em` through Forge's lesson memory, not on a page.
- Create and edit only pages the pod created, within that space. Never delete, move, or restrict a page, and never edit a page a person owns; comment on it instead.
